# 🀄 Okey Masası

## ✨ Mevcut Özellikler (`v0.3.0`)

- **3 Seviye Yapay Zekâ Bot:** Kolay (rastgele), Orta (işe yarayan taşları tutan) ve Zor (en yüksek per kombinasyonunu hesaplayıp yandan taş alabilen) botlar.
- **Sıfır Dosyalı Taş Sesleri:** Web Audio API ile anlık üretilen taş çekme, atma, karıştırma ve bitiş ses efektleri (ses aç/kapa destekli).
- **Akıcı Istaka Kontrolü:** Sürükle-bırak veya dokunarak taş dizme, atılan taş yığınlarını inceleme ve okey taşına çift dokunarak ters çevirme.
- **Tam Ekran Uyumluluğu:** Bilgisayarda 16:9 geniş masa, telefonda dikey ekrana özel 3 sıralı ıstaka yerleşimi.
- **Tek Dosya Mimari:** Ekstra kütüphane veya sunucu kurulumu gerektirmez.
